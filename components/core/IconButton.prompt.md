A round icon-only button, 48px (md) or 44px (sm). Use it for header actions such as notifications and help.
```jsx
<IconButton icon="bell" label="Notifications" badge />
```
Use `badgeCount` for an unread count, e.g. an offer that was also sent as a push notification, so it survives the push being cleared.
Variants: surface (white with a soft shadow, for the page), soft (grey), inverse (ink), glass (on dark hero cards).
