Every amount goes through Money. It uses tabular figures, a smaller "AED" in front, and keeps the amount left-to-right so it never reorders in Arabic.
```jsx
<Money amount={133200} size="hero" tone="inverse" />
<Money amount={400} sign="+" tone="in" />
```
Sizes: sm 14, md 16, lg 22, xl 28, hero 38.
